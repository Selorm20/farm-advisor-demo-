AI Farm Advisor

A working demo of the core module proposed to COCOBOD / CHED — built to show how a farmer would actually talk to the platform, in plain language, on an ordinary phone.

On iPhone: tap the Share icon in Safari, then “Add to Home Screen.”

Demo mode. Chat answers below are scripted responses covering a handful of common questions — not a live AI model — so this demo runs free, with no server and no API costs. In the piloted version, every response would come from a real AI model grounded in CHED-reviewed content, with uncertain or high-stakes cases deferred to a Community Extension Agent.
